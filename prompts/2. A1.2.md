### Planner Response

Depending on what you mean by "reverse order", here are the **3 ways** to iterate/output a map in reverse in C++:

---

### 1. Reverse Iteration with `rbegin()` and `rend()` (Descending Key Order)
If you are using `std::map<char, int>`, keys are sorted in ascending order (`'a'` to `'z'`). You can use reverse iterators to print from highest to lowest (`'z'` to `'a'`):

```cpp
map<char, int> freq;

// Populate map...

// Loop in reverse order
for (auto it = freq.rbegin(); it != freq.rend(); ++it) {
    cout << it->first << " : " << it->second << endl;
}
```

---

### 2. Declare Map with `std::greater` (Sorts Descending Automatically)
You can declare the `std::map` with `std::greater<char>` so it sorts elements in descending order from the start:

```cpp
// std::greater<char> forces descending order ('z' -> 'a')
map<char, int, greater<char>> freq;

freq['a'] = 2;
freq['z'] = 1;

// Normal loop will automatically output 'z' before 'a'
for (auto [key, count] : freq) {
    cout << key << " : " << count << endl;
}
```

---

### 3. Iterating the Original String in Reverse
If you want to print characters in the **reverse order of their original position in the string**:

```cpp
string text = "compiler";
unordered_map<char, int> freq;

// Count frequencies
for (char c : text) freq[c]++;

// Loop through the string backwards
for (int i = text.size() - 1; i >= 0; i--) {
    char c = text[i];
    cout << c << " : " << freq[c] << endl;
}
```

### Why this Error Happens

`std::unordered_map` uses a Hash Table internally. Because hash tables store elements in an unsorted, unpredictable order, **`std::unordered_map` does NOT have `rbegin()` or `rend()` reverse iterators**.

Reverse iterators are only available on ordered containers like **`std::map`**.

### Planner Response

### Why your code didn't print the *first* character in the string

Neither `std::map` nor `std::unordered_map` remembers the **original order** in which characters appeared in `text`:
- `std::map` sorts elements alphabetically (`'a'` to `'z'`).
- `std::unordered_map` stores elements in random hash bucket order.

Because of this, looping over `for (auto pair : freq)` checks characters in hash/sorted order, **not string order**.

---

### Solution

To print the first character in **original string order** that has a count of 1:
1. Build the `freq` map by looping through `text`.
2. Loop over the **original string `text`** from left to right.
3. Print the first character where `freq[c] == 1` and `break`.
