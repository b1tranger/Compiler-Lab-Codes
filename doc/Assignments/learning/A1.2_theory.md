## 1. Frequency Counting with `std::map` and `std::unordered_map` in C++

A **map** in C++ is an associative container that stores elements formed by a combination of a **key** and a **mapped value** (value). It is commonly used to count repetitions/frequencies of elements in an array or string.

### Types of Maps in C++
- **`std::map<Key, Value>`**: Implemented as a Self-Balancing Binary Search Tree (Red-Black Tree). Elements are stored in **sorted order** by key. Lookup/Insertion takes $\mathcal{O}(\log N)$.
- **`std::unordered_map<Key, Value>`**: Implemented using a Hash Table. Elements are stored in **arbitrary order**. Average lookup/insertion takes $\mathcal{O}(1)$.

---

### Syntax & Usage

#### Declaration
```cpp
#include <iostream>
#include <map>
#include <unordered_map>
#include <vector>
#include <string>

using namespace std;

// Frequency of integers in an array
unordered_map<int, int> intFreq;

// Frequency of characters in a string
unordered_map<char, int> charFreq;
```

### Counting Repetitions in an Array / String

In C++, when you access a key that does not exist yet using `mp[key]`, it automatically initializes that key with the default value (which is `0` for numeric types like `int`) and then increments it.

#### Example 1: Counting Character Frequency in a String
```cpp
#include <iostream>
#include <string>
#include <unordered_map>

using namespace std;

int main() {
    string text = "compilerlab";
    unordered_map<char, int> freq;

    // Count repetitions
    for (char c : text) {
        freq[c]++;
    }

    // Display frequencies
    cout << "Character Frequencies:" << endl;
    for (auto pair : freq) {
        cout << "'" << pair.first << "' : " << pair.second << endl;
    }

    return 0;
}
```

#### Example 2: Counting Integer Frequency in an Array
```cpp
#include <iostream>
#include <vector>
#include <unordered_map>

using namespace std;

int main() {
    vector<int> arr = {4, 2, 4, 5, 2, 3, 4, 2, 1};
    unordered_map<int, int> freq;

    // Increment count for each number
    for (int num : arr) {
        freq[num]++;
    }

    // Print frequencies
    cout << "Element Frequencies:" << endl;
    for (auto [element, count] : freq) { // C++17 structured binding
        cout << element << " occurs " << count << " times" << endl;
    }

    return 0;
}
```

---

### Key Operations Cheat Sheet

| Operation | Syntax | Description |
| :--- | :--- | :--- |
| **Increment Count** | `freq[x]++` | Adds `1` to the count of element `x`. Creates `x` with count `1` if not present. |
| **Check Existence** | `if (freq.count(x))` or `if (freq.find(x) != freq.end())` | Checks if element `x` exists in the map without accidentally inserting it. |
| **Access Count** | `freq[x]` | Returns the current count of `x`. |
| **Size of Map** | `freq.size()` | Returns the total number of unique keys present. |

### Reversing Output Order in Map (`std::map`)

By default, `std::map` sorts keys in **ascending order** (`'a'` to `'z'` or `1` to `N`). 

To print/output the map in **reverse order**, you have two main approaches:

#### Approach 1: Using Reverse Iterators (`rbegin()` and `rend()`)
Use `rbegin()` (reverse begin) and `rend()` (reverse end) with a standard **`std::map`** (ordered container):

> [!WARNING]
> Reverse iterators (`rbegin()` / `rend()`) only work with **`std::map`**. They do **NOT** work with `std::unordered_map` because hash tables have no concept of key order!

```cpp
map<char, int> freq; // Must use map, NOT unordered_map
// ... populate freq ...

// Iterate in reverse (Descending key order: 'z' to 'a')
for (auto it = freq.rbegin(); it != freq.rend(); ++it) {
    cout << it->first << " : " << it->second << endl;
}
```

#### Approach 2: Declaring `std::map` with `std::greater` Comparator
Declare the map with `greater<KeyType>` so keys are automatically sorted in descending order:

```cpp
// Stores keys in descending order by default
map<char, int, greater<char>> freq;

freq['a'] = 1;
freq['z'] = 5;

// Standard loop will automatically output 'z' first, then 'a'
for (auto [key, count] : freq) {
    cout << key << " : " << count << endl;
}
```

#### Approach 3: Reversing String Order First (Preserving String Order in Reverse)
If you want to process characters in reverse order of how they appeared in a string:

```cpp
string text = "compiler";
unordered_map<char, int> freq;

// Populate map
for (char c : text) freq[c]++;

// Loop string in reverse
for (int i = text.size() - 1; i >= 0; i--) {
    char c = text[i];
    cout << c << " occurs " << freq[c] << " times" << endl;
}

### Finding the First Non-Repeating Character

> [!IMPORTANT]
> Neither `std::map` nor `std::unordered_map` keeps track of the **original insertion order** of characters in a string.
> - `std::map` sorts alphabetically (`'a'` to `'z'`).
> - `std::unordered_map` stores in arbitrary hash order.
> 
> Therefore, iterating over the **map** directly will **NOT** guarantee you get the character that appeared **first** in the string.

#### Correct Approach:
1. Build the frequency map by looping through `text`.
2. Loop through the **original string `text`** a second time from left to right.
3. Check `freq[c] == 1` for each character. The first one you encounter is guaranteed to be the first non-repeating character in the string order.

```cpp
#include <iostream>
#include <string>
#include <unordered_map>

using namespace std;

int main() {
    string text;
    cin >> text;

    unordered_map<char, int> freq;

    // Step 1: Count frequency of each character
    for (char c : text) {
        freq[c]++;
    }

    // Step 2: Iterate over string in original order to find first unique character
    for (char c : text) {
        if (freq[c] == 1) {
            cout << "First non-repeating character: " << c << endl;
            break; // Stop at the very first one found
        }
    }

    return 0;
}
```

## 2. String Indexing and `char` Assignment in C++

In C++, `std::string` is stored as a contiguous sequence of `char` values.

### Storing `string` Index Value into a `char` Variable

You can extract a character from a string using bracket notation (`text[i]`) and store it directly in a `char` variable.

```cpp
string text = "hello";
char rep = text[0]; // Stores 'h' in rep
```

### Important Details:
- **Type**: `text[i]` returns a reference to a single `char` (`char&`).
- **Assignment**: Assigning `rep = text[i]` copies that single character into the variable `rep`.
- **Bounds Safety**: Always ensure index `i` is within range `0 <= i < text.size()`.
