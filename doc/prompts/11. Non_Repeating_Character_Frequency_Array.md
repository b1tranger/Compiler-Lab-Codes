#include<iostream>
#include<string>
 using namespace std;

 int main(){
 string s= "swiss";
int count[26] = {0};

for(char c : s){
    count[c - 'a']++;
}

for (char c : s){
    if (count[c - 'a'] == 1){
        cout<<c;
        return 0;
    }
}

## 3. Analysis & Key Insights

1. **Algorithmic Mechanics (Two-Pass Scanning)**:
   - **Pass 1 (Lines 9–11)**: Iterates over the string to construct the character frequency table. For each character `c`, its zero-based position in the alphabet `c - 'a'` is incremented in `count`.
   - **Pass 2 (Lines 13–18)**: Iterates through the original string in left-to-right order. The first character encountered whose `count[c - 'a'] == 1` is immediately printed, and the program terminates.
   - **Fallback (Line 19)**: If all characters occur more than once, prints `-1`.

2. **ASCII Index Arithmetic (`c - 'a'`)**:
   - Lowercase letters `'a'` through `'z'` have sequential ASCII codes $97$ through $122$.
   - Subtracting `'a'` (97) normalizes the range to $0$ through $25$, fitting directly into a 26-element integer array.

3. **Complexity Analysis**:
   - **Time Complexity**: $\mathcal{O}(N)$ where $N$ is the length of string $s$. Both loops run in linear time.
   - **Space Complexity**: $\mathcal{O}(1)$ or $\mathcal{O}(\Sigma)$ auxiliary space, where alphabet size $\Sigma = 26$. This uses stack memory (104 bytes), with zero dynamic heap allocation and zero hash collisions.

4. **Safety & Robustness Limitations**:
   - The expression `c - 'a'` assumes strictly lowercase characters (`'a'`–`'z'`).
   - If uppercase letters (ASCII $65$–$90$) or punctuation/spaces are supplied, `c - 'a'` yields negative indices, leading to out-of-bounds memory access (Undefined Behavior).
   - For general text, an `int count[256] = {0}` table with `unsigned char` indexing or `std::unordered_map<char, int>` should be used.
