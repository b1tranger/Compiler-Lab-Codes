## 3. Analysis & Key Insights
1. **Pushdown Automata (PDA) vs Counter**:
   - Scalar depth counters (`openCount`) only suffice for single delimiter types `()`.
   - Real-world mathematical and compiler grammars support heterogeneous delimiter hierarchies: `()`, `[]`, `{}`.
   - For strings with multiple delimiter types like `(2+[3*4)]`, a scalar counter cannot distinguish delimiter types or detect LIFO violations. A stack (`std::stack<char>`) is mathematically required (Dyck-k language).
2. **Stack Underflow & Mismatch Checking**:
   - On seeing any opening bracket (`(`, `[`, `{`), push to `bracketStack`.
   - On seeing any closing bracket (`)`, `]`, `}`):
     - Check for underflow (`bracketStack.empty()`).
     - Check top element for matching pair (`isMatchingPair(top, curr)`).
     - Pop matching opening delimiter.
3. **Infix Grammar Invariants Preserved**:
   - Lookahead checking (`i + 1 < n`) prevents consecutive operators, empty brackets, and illegal operand concatenations without operators.
   - Preserves all safety measures (`static_cast<unsigned char>` for `<cctype>`, `static_cast<int>` for string size).
