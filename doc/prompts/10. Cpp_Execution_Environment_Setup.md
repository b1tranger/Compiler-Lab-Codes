## 3. Analysis & Key Insights

1. **PowerShell 5.1 Compatibility**:
   - The default integrated shell on Windows is Windows PowerShell 5.1.
   - Unlike POSIX shells or PowerShell 7+, PowerShell 5.1 does not support `&&` for command chaining, returning `ParserError: The token '&&' is not a valid statement separator in this version`.
   - The correct pattern is:
     ```powershell
     cd "$dir"; g++ -Wall -Wextra -std=c++20 "$fileName" -o "$fileNameWithoutExt.exe"; if ($?) { .\"$fileNameWithoutExt.exe" }
     ```
2. **Interactive I/O in VS Code**:
   - By default, the Code Runner extension runs programs in the "Output" panel, which does not allow stdin keyboard input. Interactive programs using `cin >> ...` appear frozen.
   - Setting `"code-runner.runInTerminal": true` routes execution to the integrated terminal, enabling interactive input.
3. **Toolchain Location**:
   - The system utilizes `g++ (GCC) 15.2.0` under MSYS2 at `C:\msys64\usr\bin\g++.exe`. Executables produced run directly in standard Windows terminals as `C:\msys64\usr\bin` is present in `PATH`.
