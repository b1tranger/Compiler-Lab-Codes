## 3. Analysis & Key Insights

1. **Range-Based `for` Loop Fundamentals (C++11)**:
   - Syntax: `for (declaration : collection)`
   - Under the hood, the compiler expands this to an iterator-based loop:
     ```cpp
     for (auto it = collection.begin(); it != collection.end(); ++it) {
         declaration = *it;
         // loop body
     }
     ```

2. **Loop 1: `for (string s : st)`**:
   - `st` is of type `vector<string>`.
   - Each element is an instance of `std::string`.
   - On each iteration, the next string in `st` is **copied by value** into the local variable `s`.
   - **Optimization**: Writing `for (const string &s : st)` avoids deep heap string copying.

3. **Loop 2: `for (auto pair : mp)`**:
   - `mp` is of type `unordered_map<string, vector<string>>`.
   - In C++, associative containers store entries as `std::pair<const Key, Value>`.
   - Here, the element type is:
     ```cpp
     std::pair<const std::string, std::vector<std::string>>
     ```
   - **The Role of `auto`**: The compiler deduces `pair` to be `std::pair<const string, vector<string>>`.
   - **Member Fields**:
     - `pair.first` is the canonical sorted signature key (`string`).
     - `pair.second` is the bucket of original anagram words (`vector<string>`).
   - **Copy by Value Issue**: `auto pair` copies the entire `pair`, creating deep copies of the nested `vector<string>` every single iteration.
   - **Modern C++ Idiom (Structured Bindings)**:
     ```cpp
     for (const auto &[key, words] : mp)
     ```
     This binds `key` as `const string&` and `words` as `const vector<string>&` with zero copying.

## 4. Final Solution & Output

### Example Demonstration
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <unordered_map>

using namespace std;

int main() {
    vector<string> st = {"eat", "tea", "tan"};
    unordered_map<string, vector<string>> mp;
    mp["aet"] = {"eat", "tea"};
    mp["ant"] = {"tan"};

    // Loop 1: Iterating vector
    for (const string &s : st) {
        cout << "Word: " << s << endl;
    }

    // Loop 2: Iterating map with pair
    for (const auto &pair : mp) {
        cout << "Key: " << pair.first << " -> Count: " << pair.second.size() << endl;
    }

    return 0;
}
```
